# CODE.md

**An end-to-end automated testing framework for AI coding agents, built on real code callgraphs.**

CODE.md's callgraph tells an agent exactly which tests a change requires, so it can run only those, generate the ones that don't exist, and fix the code when a test genuinely fails — never a self-reported pass. That loop is backed by a single, structured Markdown file with a reliable map of your repository: languages, structure, entry points, callgraphs, UI flows, TODOs, and known gaps.

CODE.md files are auto-generated by [CodeMD.dev](https://codemd.dev), using parser-based extraction from the actual repository instead of guessed summaries.

**README.md is for humans.**  
**AGENTS.md is for agent behavior.**  
**CLAUDE.md is for Claude-specific context.**  
**CODE.md is for the codebase itself.**

---

## Why CODE.md?

AI coding agents that edit code either run an entire test suite for a one-line change (slow, expensive) or skip testing it altogether (risky) — and when a test does fail, they often just report a pass/fail claim instead of proving it. Worse, without real repository context they can hallucinate architecture, routes, dependencies, or code flow.

CODE.md's callgraph fixes the test problem, and its structured map fixes the context problem.

It helps AI agents:

- Run only the tests a change's callgraph impact actually requires, not the whole suite
- Generate a test for a function that has none
- Fix code from a real, hard-fact test failure, then re-verify — never trust a self-report
- Understand the repository faster
- Follow real code flow
- Find entry points and important files
- Use parser-generated callgraphs and filegraphs
- Reduce hallucinations
- Avoid repeated repo exploration
- Save developer time and token cost

---

## What is CODE.md?

CODE.md is a structured Markdown file placed in the root of a repository.

It gives AI coding agents a parser-generated testing loop, plus the repository understanding that loop is built on:

- Callgraph-linked test coverage, execution, generation, and repair
- Callgraph summary
- Repository structure
- Primary languages
- Entry points
- API routes
- Modules and responsibilities
- Filegraph summary
- UI flows
- TODOs and known gaps
- Behavior constraints
- Validation notes

A CODE.md file can be written manually, but it is most useful when it is auto-generated from real repository evidence.

---

## Where CODE.md fits

CODE.md is one of the core files for AI-assisted development:

| File | Purpose |
|---|---|
| `README.md` | Explains the project to humans |
| `AGENTS.md` | Tells AI agents how to behave |
| `CLAUDE.md` | Gives Claude-specific project context |
| `CODE.md` | Runs the tests an AI agent's change requires, generates what's missing, and fixes what fails |
